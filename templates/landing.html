ABOUT THE PROJECT

A Simple Invoice Management System

Invoice Generator is a Flask-based web application designed to simplify invoice creation and management.

Users can create invoices with multiple products, automatically calculate GST and totals, generate PDF invoices, and review their invoice history.

The project also includes user authentication, password recovery, database management and business analytics.

Python Application Logic
Flask Web Framework
SQLite Database
ReportLab PDF Generation
